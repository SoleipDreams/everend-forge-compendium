# Forge background scenes

Generated for Everend Forge on 2026-10-09 using the built-in image_gen tool,
without input photographs. Fictional nebular concept art, not telescope imagery.

- amber: muted amber / slate blue
- violet: deep indigo / soft violet
- jade: deep teal / muted emerald
- copper: copper brown / dark burgundy

Production specification: an original wide composition of softly defocused,
low-contrast nebular clouds with nearly black shadows, suitable behind a writing
workspace. No stars, dots, planets, people, ships, text, logos, UI or collages.

JPEG files are thumbnails; matching SVG files embed the JPEG with a Gaussian
blur (standard deviation 36). Images are bundled locally and do not require a
remote image service. These scenes are independent of the regular canvas grid.
