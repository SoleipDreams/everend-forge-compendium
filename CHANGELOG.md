# Changelog

Notable changes to Everend Compendium are documented here.

## [0.5.1] - 2026-11-25

### Changed

- Refreshed the Spanish and English learning tours to match the current Index,
  Stories, reader, and publication-profile views.
- Clarified that Preview and Diagnostics help review an edition, while the ZIP
  is created only after running the prepared command with the Compendium CLI.
- Updated the tour copy to explain which steps are optional and what each view
  changes, without suggesting that browsing the tour publishes content.
